# 03方向原生实施

2026-10-20，用户在确认03原画Eous/圆角清单后要求“继续”，本阶段将新原型落实为实际Windows界面。原型保留在上级目录，未用旧产品视觉作为设计来源。

## 完成范围

- WPF主页：980×700，两组开放清单，六项标准工具进入首屏；侧栏原画完整融入导航下方，在900×600随可用空间缩小。
- 统一暖白、鼠尾草绿与橙色主操作，12px自绘控件；窗口/托盘/EousFolderHop图标统一使用Eous。未使用软胶、抽象或哥特生成图。
- 46×26开关继续使用现有真实生命周期、即时请求方向、忙碌保护、失败回弹与UIA。状态文字独立表达实际状态；处理中不误显示路径修复。
- 设置从右侧滑入：文件触发/打开方式横向页签，通用/网页/目录/程序/关于共用正文锚线与色阶。保留原有配置、高级字段、恢复、帮助与保存能力，关于页只读。
- 通用及文件/网页草稿关闭提供继续编辑/放弃/保存；失败保留输入；自定义及预设程序异步保存期间保护抽屉与主窗口。
- 辅助面板共享圆角与新默认配色；WinForms目录窗口修正动态控件DPI缩放。旧A/B配置ID保持兼容，辅助面板外观收进通用设置的折叠项。

未新增业务功能、接口或外部依赖，未改变真实工具的启停策略、进程匹配与配置结构。实际用户软件没有被用于停止测试。

## 素材一致性

原始`eous-reference.png`实际编码为透明WebP；WPF解码出现黑底，因此仅转换编码为RGBA PNG。已验证转换前后解码后的RGBA像素逐字节相同。`Assets/EousCharacter.png`内嵌到程序，保留完整原画；窗口图标继续使用现有Eous ICO。

## 动效与减法

保留工具行轻微错峰渐入；开关20px滑动与处理中反馈；抽屉从右侧36px渐入并原路退出；草稿确认采用同一圆角语法。关闭系统客户端动画或高对比度时回退到稳定终态。

主页外部工具说明收敛为剪贴板管理/文件搜索/语音输入，进程范围说明仍保留在设置；去掉主页头像和重复统计，关于页去掉无关保存操作。功能说明与错误原因保留。

`dialog-motion/frames.json`及逐帧截图记录原生抽屉时序；开关插值、重复通知与逆向切换由原生测试核验。没有完整动效视频独立验收，不以静态图或离屏帧替代手感结论。

核心验证命令：`Tests/run-tests.ps1 -Configuration Release`，通过`publish.ps1`默认流程执行；发布命令为`./publish.ps1 -OutputPath artifacts/EousAssistant-v0.2.0-beta.15-win-x64`。

单独调试验证包含基础76项、`--assistant-smoke`、`--workbench-smoke`、`--custom-program-smoke`。开关与设置草稿异步状态连续3轮核验，覆盖保存读回、保存失败、关闭保护、最小尺寸、100/125/150/200%离屏图与原生窗口样式。

实际截图在`shots/`。WPF图以96 DPI逻辑单位渲染；WinForms原设备图为144 DPI，另提供96 DPI归一图比较，数据在`shots/folder-capture-dpi.txt`。这不是实际监视器缩放全矩阵验收。
