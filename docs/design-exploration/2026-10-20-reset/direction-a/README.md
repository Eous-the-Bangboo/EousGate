## 设计决定

北极星：打开就知道哪些工具在工作，并能在对应工具旁完成下一步。

保留 A 的白灰底、少量朱红、左侧精简导航与开放清单。首页六个工具完整显示，名称、用途、真实状态与启停/修复动作保持同一行；复杂设置以右侧详情按需出现。没有加入指标卡、角色大图或大面积装饰。

相比首屏候选，精简重复的正文品牌字标，在左侧补入三个工具设置入口；移除页脚无助于操作的刷新频率说明。文件类型配置把当前后缀固定在上方，软件显示勾选与排序分别操作。Everything 的路径说明直接承接启动失败原因，不另堆告警面板。

默认窗口 980×700，主要字体 Microsoft YaHei / Segoe UI Variable；标题22–23px、正文14px、辅助13px。颜色、空间、控件与浮层统一由 styles.css 中的变量与规则维护。界面不需要独立情绪图片，以工具内容和小尺寸线性图标建立识别。

## 页面与流程

- 工具总览：单项启动/停止、启动中/停止中、全部启停、单项失败、添加程序、关闭面板后恢复。
- 文件快开：边缘组合、候选数量、收起延迟；文件类别/后缀搜索、自定义后缀、已自定义筛选、显示与排序、当前后缀/整类恢复推荐及明确范围确认。切换后缀保留未应用草稿。
- 网页快开：检测、位置、停留时间、连续复制自动打开与次数，开关从属选项，链接提示预览。
- 文件夹快跳：记录与辅助按钮、目录选择、导入、清空普通历史且保留收藏。
- 程序管理：名称/路径/参数、超时强制结束选择、运行中编辑限制、重复路径与助手自身阻止、移除范围确认。
- 通用设置与关于：主题预览/保存、诊断开关、原生工具与关闭/退出语义。
- 三类浮层：软件选择（含空候选和系统入口）、链接提示（含悬停/键盘暂停、重试）、目录选择（含搜索、收藏、已打开、移除、空状态和跳转）。

可直接以 `?state=home`、`file`、`file-apps`、`web`、`folder`、`program`、`general`、`about`、`open`、`links`、`folders`、`open-empty`、`folders-empty`、`links-failed`、`unsaved`、`save-error` 打开代表状态。`?state=web&fault=save` 可触发一次保存失败，然后正常重试。

## 原型边界

这是设计交付，不是新的 Windows 应用构建。没有修改 WPF、运行真实工具、启动外部程序、打开真实文件/网址、注册快捷键或切换系统目录。工具状态、EXE 选择列表、目录内容与链接内容用于可操作的设计验证，不代表当前电脑实际状态或安装路径。外部程序图标使用中性符号。

设置、程序列表、目录收藏等保存在预览浏览器独立的 `eous-assistant-design-a-v1` 数据键中，不读取或修改 EousAssistant 的配置文件。导入入口只把用户明确选择的兼容 JSON 记录导入此浏览器原型，无法替代真实应用的数据迁移兼容验收；导入失败保留原记录和输入源文件。

已实现桌面可用工作区缩小时的重排与纵向滚动。200%截图为720×450逻辑视口、两倍像素密度的等效检查，不代表真实WPF、多显示器或监视器DPI验收。

## 动效

- 主操作：80ms按下反馈；启停立即进入处理中，约520ms后给出结果文字；保存中禁用重复操作，失败保留输入。
- 状态来路：右侧详情以36px位移和透明度在280ms内落位，关闭180ms；遮罩同步收放。
- 首次出场：工具行依阅读顺序间隔45ms、最多6px位移，仅首次进入播放。
- 开启减少动态效果时移除位移与动画，信息和动作仍完整可用。

动效探测报告确认首次出场6个元素、最大位移6px，配置抽屉36px位移及透明度变化。缺少ffmpeg，未生成正常速度完整录屏；保留起、中、末三帧，不把它们当作完整录屏验收。
