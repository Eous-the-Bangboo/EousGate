## 三个方向

- 抽象构成：切纸般几何平涂，米白/黑/围巾橙，荧绿只作角色识别。所有界面轮廓0px，滑轨与滑块均方角。
- 哥特墨绘：黑墨刻线与旧银/象牙白，保留焦橙围巾和荧绿眼睛，酒红用于控件强调。所有界面轮廓0px；不使用城堡、骷髅等与角色无关装饰。
- 软胶玩具：软胶潮玩材质，奶油白/墨绿/焦橙。所有界面轮廓只采用12px圆角，滑轨/滑块同一圆角规则。

统一范围包括应用窗口、角色容器、导航选中底、按钮、输入、启停滑轨和滑块。角色自身的椭圆眼、长耳和布料曲线属于角色造型，不为了界面直角规则破坏身份。

## 启停语义

六个工具的独立启停改为滑动开关，运行时滑块在右，未运行时在左，并单独保留状态文字。Everything配置失效时显示失败原因、禁用开关和修复路径入口；不能用“关闭”掩盖失败。批量启动/关闭属于命令操作，首屏保留命令按钮。

本轮方向首屏不接交互、不进行真实启停，不改WPF或原A已交付的完整原型。选择后再实现开关的请求反馈、真实状态确认、失败回弹和键盘操作，扩展至所有界面。

角色变体使用内置 image_gen 制作，原图不覆盖；最终素材与实际提示词在 assets/ 下留档。三个HTML、manifest与对比页位于本目录。完成后补充实际截图核查结果。
