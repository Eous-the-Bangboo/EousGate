# 第 01 轮：三方向首屏对比

打开 `style-explorer.html` 可离线并排比较，单张查看时可切换到实际尺寸。源文件为 a.html、b.html、c.html，内容源为 common-content.json，方向与视口由 manifest.json 描述。

- A 工具清单：980 × 700，完整工具清单与固定状态/动作列。
- B 三路操作台：1000 × 720，三条原生工具通道与外部程序列表。
- C 紧凑命令面板：640 × 620，小窗口、聚焦行与固定动作区。

三方向使用相同六工具、用途、运行状态和失败原因。状态是设计比较用的模拟数据；页面未连接实际工具，首屏按钮不执行启停或保存。外部程序图标是中性识别符号，不作为官方品牌图标交付。

本轮仅比较首屏方向：不做其他页面、交互、响应式或动效，不修改 WPF。方向选定后直接深化完整页面；也可提出要比较的版式。A 推荐用于日常状态扫描和工具列表扩展，B 更强调三原生工具，C 更强调托盘短时操作。

截图位于 shots/explore/，视觉检查结果将在本轮完成后补充。
