# ADR 0007：米哈游启动器接力识别与定向授权关闭

状态：已接受，2026-10-20。用户反馈自定义米哈游启动器只能打开不能关闭，并确认其窗口关闭只缩到托盘。本决策扩展ADR0005/0006，不改变默认不强制结束策略。

- 启动路径保持用户选择的根目录launcher.exe；仅自定义条目、该文件名且版本元数据公司名为miHoYo时，识别同一安装根目录直接数字版本子目录中的同公司HYP.exe。不递归游戏目录、不纳入HYPHelper/其他子进程，不按窗口标题或模糊进程名控制。
- 监控、独立启停、重复启动判断、运行中编辑保护和关闭确认共享这个有限路径集合。停止仍固定句柄，复核完整路径、当前用户/会话及创建时间；本次快照以外的新进程不自动结束。
- 正常关闭只发送WM_CLOSE；缩到托盘不等于退出。原“超时强制结束”必须由用户显式勾选，识别启动器后设置页显示说明并展开高级项，不擅自变更该选择。
- 仅显式停止（含用户触发的批量停止）返回Windows访问拒绝5时，普通权限助手可请求Windows授权运行自身的短时关闭工作器；助手主进程不提升权限。检测/刷新不请求授权；取消授权只使本次停止失败、保留进程和重试能力。
- 工作器在单实例与主界面初始化前执行固定入口。请求仅包含启动路径、工具ID、观察到的PID/创建时间/路径/会话及强制选择，不接受任意命令或退出参数、不启动目标软件、不递归提权。工作器重新按配置限定路径和当前身份检查，固定句柄后关闭/按已选策略强制结束，完成后退出。
- 本轮对真实HYP仅只读检查：匹配到HYP.exe，原文件清单显示requireAdministrator；不实际关闭用户启动器、游戏或其他软件。关闭与授权调度使用专用夹具；真实UAC确认和托盘启动器退出留给用户现场复测。

验证包含路径/发布者/版本目录边界、同名游戏目录排除、bootstrap退出后的状态、重复启动幂等、目标关闭、权限拒绝授权调度、请求校验及等权限工作器执行。不得把模拟授权或等权限执行记为真实UAC通过。
