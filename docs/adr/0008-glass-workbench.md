# ADR 0008：轻透玻璃工作台

- 日期：2026-11-09
- 状态：已采用
- 版本：v0.3.0-beta.1

## 背景

用户参考 bilibili-margin 的透明美术方向，确认本聊天的 Eous 轻透玻璃交互稿，并要求落实为原生应用。研究见 [设计笔记](../design-exploration/2026-11-08-margin-study.md)。视觉和导航变化明显，使用新的 0.3 次版本；本轮不改变工具生命周期和配置结构，先发 beta.1 验证桌面体验。

## 决策

- 主窗口使用暖白／烟灰底色、鼠尾草绿环境色、橙色主操作、细亮边和 Eous 原画。左侧仅“我的工具／通用设置／关于”，工具设置从行尾齿轮进入；两组标题为“快捷工具／常用程序”。保留独立开关及全部启动／全部关闭。
- `GlassResources` 统一材质画刷，背景透明度与前景文字分层；不降低整个控件树的透明度，不对文字模糊。
- 主窗口保持非 layered 的 WindowChrome HWND。Windows 11 22H2（build 22621）以上通过公开 DWM API 请求 `DWMSBT_TRANSIENTWINDOW`，让系统提供背景材质；读取系统透明效果和应用深浅偏好，并响应系统偏好变化。
- 高对比度、系统关闭透明、不支持的版本、DWM 失败时回退到有实体底色的材质。高对比度使用不透明系统色。系统背景模糊的具体表现由 Windows、窗口激活状态和桌面环境决定。
- 设置抽屉、文件打开面板和链接提示沿用已有 layered 输入模型，使用接近不透明的有色材质与细边框；不声称这些窗口具备实时桌面模糊。抽屉加厚至 250/255 基础不透明度，避免下层文字干扰。
- A/B 的配置 ID 保留，B 辅助面板继续使用平面深色主题；不引入新的依赖、后台网络或配置迁移。

## 验证与边界

基础测试覆盖材质启用条件和高对比度不透明资源；WPF 回归覆盖真实窗口、独立开关、失败回弹、设置保存／关闭保护，以及深浅主题和缩放渲染。离屏图用于确认布局和颜色，不能证明桌面合成模糊、实际显示器 DPI 或真实跨应用拖放。完整记录见 [发布记录](../releases/v0.3.0-beta.1.md)。
