# 采用独立 WPF 程序，而不是 Windows Shell 插件

状态：已接受。

EousGate 第一版采用 C#/.NET + WPF 的独立绿色桌面程序，并通过 Windows Shell 能力读取“打开方式”和启动选定软件；暂不实现 Windows Shell 插件。这样可以在不修改资源管理器和系统外壳的前提下完成边缘唤出、悬浮面板和系统托盘，降低安装、签名、权限和 Windows 版本兼容成本。代价是程序必须在用户手动启动后运行，无法像系统内置功能一样天然覆盖所有会话；如果未来需要更深的系统集成，再单独评估插件或外壳扩展方案。

## 后果

- 首版必须明确说明“不自动开机启动”和“仅主屏单屏支持”。
- Windows API 访问集中在适配层，未来更换 UI 框架或接入 Shell 扩展时不影响领域接口。
- 绿色发布不提供安装器、自动更新和卸载向导，这些能力留到后续版本。
