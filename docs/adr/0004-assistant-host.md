# EousAssistant：统一宿主与独立工具生命周期

状态：已接受，2026-10-16。依据用户确认的统一助手方案。

## 产品和交互

- 产品为 EousAssistant（Eous 助手）；EousFileHop（文件快开）、EousWebHop（网页快开）、EousFolderHop（文件夹快跳）为三个内置工具。
- 一进程、一托盘。打开助手显示工具列表，不自动启动模块；勾选持久化，运行状态每次从未运行开始。
- 每行独立启动、停止、设置；批量提供启动勾选、关闭勾选、全部启动、全部关闭。关闭操作等同停止运行，不删除数据。
- 关闭面板保留工具；退出助手停止工具并保存数据。第二次启动通过本地事件唤回面板。

## 契约与实现

- `ToolDescriptor` 使用稳定 ID `file-hop`、`web-hop`、`folder-hop`，包含中英文名、说明、图标、`ToolKind` 和 `ToolCapabilities`。
- `IAssistantTool` 暴露异步 Start/Stop、真实状态、错误、勾选和状态通知；`ManagedTool` 串行化单项转换，确保幂等及失败清理。
- `ToolManager` 注册目录并按启动时选择快照执行批量操作，单项错误不阻止后续工具。面板从目录生成条目。
- `ToolKind.External` 及能力标记是后续进程适配入口，本版本不启动外部进程、不扫描插件、不提供假条目。
- 原项目文件和内部 `EousGate` 命名空间保留以减小兼容风险；程序集、产品名和发布入口改为 EousAssistant。
- 保留现有 WPF 主题、窗口样式与 WinForms 互操作。FolderHop 核心、Shell 读取、按钮和选择窗口移植到 .NET 8，不运行第二个消息循环或托盘。
- FolderHop 使用可取消的 STA 工作线程，停止时注销快捷键、取消导航计时器并等待线程结束。COM 超时明确显示失败，保留会话所有权以允许重试停止。
- 通过旧版命名互斥对象检测冲突并阻止重复监听，不结束用户旧程序。

## 数据与兼容

- 助手配置迁移到用户 LocalAppData 的 EousAssistant 目录；只在新配置不存在时读取旧 EousGate 设置，复制保存且保留源文件。
- 旧全局暂停与网页禁用转换为默认勾选，不恢复实际运行状态。
- FolderHop 历史单独存储；用户通过设置选择旧历史文件，按标准化路径合并，收藏取并集、时间取最新。先完整解析，失败不更改当前数据，源文件不写入。
- 配置原子写入，保留备份；损坏读取失败不覆盖原文件。文件夹历史保留原实现的备份恢复及清空历史时清除旧备份行为。
- 目录历史是用户启用文件夹工具后的本机功能数据；诊断仍禁止路径、文件名、内容或网址。
- 不添加网络依赖、服务、自动更新、开机启动或文件关联修改。

## 验证边界

自动回归、离屏渲染和真实宿主无输入启停检查由测试程序集运行。原生对话框及 Edge 的完整跳转、实际多 DPI/高对比度桌面与 Shell 切换行为须作为独立桌面验收记录，不以离屏渲染代替。
