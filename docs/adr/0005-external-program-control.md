# 外部程序监控与显式启停

状态：已接受，2026-10-16。扩展 ADR 0004 的外部工具接口；用户要求首先接入 Ditto、Everything、无线麦 Sayall。

## 界面与操作

- 主列表按 Kind 分为“Eous原生工具”和下方的“非Eous原生工具”，共用条目模板与滚动区域，各自显示运行／勾选数量。
- 三个外部工具具有独立启动、停止、设置、勾选；四个批量按钮覆盖整个列表。
- 打开助手不自动启动外部应用。控制面板正常显示或最大化时每两秒读取真实进程状态，失去焦点继续；最小化、隐藏、关闭到托盘时暂停定时检查，无面板初始化不检查。首次打开和恢复面板立即刷新全部外部工具，外部手动启动、退出反映到面板。
- 监控启停集中在宿主：窗口可见性、窗口状态与宿主退出状态共同决定定时器生命周期。每轮刷新串行且防重入；暂停允许正在读取的一项完成，随后中止剩余项。可见性代次阻止旧轮次在快速恢复后继续，恢复请求合并为一次完整刷新，不补跑历史定时任务。关闭与宿主释放解除窗口事件订阅。
- 暂停只影响周期观测，保留上次状态，原生模块和外部软件继续运行。显式启停、路径配置仍执行必要的即时身份检查与结果确认，不受面板可见性限制；配置格式不变。
- 外部软件已运行时启动为幂等操作；点击停止或批量关闭会关闭该应用。退出助手只停止内置模块，保留外部软件并释放监控器。
- 软件路径自动从当前进程、常规安装目录、卸载注册信息定位；设置允许选择对应程序的 EXE。已运行时禁止切换目标路径。

## 进程适配与边界

- ExternalProgramTool 实现 IAssistantTool，自行跟踪观测状态并串行化启停、刷新和路径修改。启动／停止后的状态须重新读取，不能把 Process.Start 返回视为成功。
- WindowsExternalProgramController 仅匹配预设程序文件名、完整路径、当前会话与当前用户 SID，Windows 服务、其他会话及其他安装位置不作为管理对象。
- 停止前打开并保留原进程句柄，复核创建时间和路径，避免 PID 重用；不使用整个进程树终止，避免影响不属于该工具的子程序。
- Ditto 使用 `/Exit` 请求退出，Everything 使用 `-exit`；Sayall 向同路径应用窗口请求关闭。等待正常退出后，对尚未退出且身份一致的原进程执行后备终止。主进程及同 EXE 路径的辅助进程作为一个工具处理。
- 停止后等待退出命令自身与目标进程结束，仍检测到进程则显示失败并支持重试；路径／权限不可确认时不继续控制。
- beta.2 当时仅支持三个预设（beta.6 的用户自定义扩展见 [ADR 0006](0006-custom-program-monitoring.md)），不提供通用插件加载、自动安装或崩溃自动重启，不修改软件配置、系统服务或开机启动。

退出命令依据开发者原始文档：[Ditto Command Line Options](https://github.com/sabrogden/Ditto/wiki/Command-Line-Options)、[Everything Command Line Options](https://www.voidtools.com/support/everything/command_line_options/)。

## 数据与验证

- 外部路径写入现有 UserSettings.ExternalPrograms，勾选沿用 ToolSelections；旧配置缺少这些字段时正常补默认值。
- 设置复制、通用设置应用必须保留外部路径；诊断仍不写路径、进程命令行或应用内容。软件本身不发网络请求。
- 自动化用专用测试 EXE 验证启动、正常退出、后备停止、同名不同路径隔离、创建时间／会话校验及辅助进程处理，不重启用户的真实软件。
- 默认测试增加 `--external-monitor-lifecycle-smoke`，注入可计数、可延迟的假控制器，覆盖无面板、失焦、最小化／隐藏／关闭、恢复、慢检测中暂停和快速恢复、启停中最小化及宿主退出；`--external-monitor-smoke` 仍为可选已安装应用只读检查，先验证无面板未观测，再打开面板读取状态。
- 本机三款软件完成真实只读定位与宿主监控。真实应用的退出保存行为、录音中停止等场景未执行破坏性实测。
