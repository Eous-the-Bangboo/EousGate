# ADR 0006：用户自定义程序监控

状态：已接受，2026-10-16。扩展 ADR 0005 的三个预设，用户授权来自“解释并支持自定义应用监控”及当前实施请求。

## 决策

- 普通 EXE 使用 `CustomMonitoredProgram` 列表持久化：稳定 `custom-<GUID>` ID、名称、完整路径、可选启动参数、超时强制结束选择；默认不强制。
- 首页非Eous原生工具分组提供“添加程序”；行内设置编辑或移除。自动读取名称及图标，名称可改。移除只取消管理，不停止、卸载或删除程序。
- 复用 `ExternalProgramTool` 和现有控制器、身份校验、启停确认及面板显示期间的两秒监控。程序存在只表示进程存在，不是健康检查或崩溃自动重启。
- 自定义定义按指定 EXE 名称、完整路径、当前用户及会话匹配；停止使用固定句柄和创建时间校验。同路径同名辅助进程归为同一程序，不泛化为任意子进程树。
- 参数直接交给 EXE，默认使用 `UseShellExecute=false`，不经命令解释器。beta.8 仅在显式启动返回 Windows 740（需要提升）时，将原 EXE、工作目录及参数原样交给 Windows Shell 的 open 动作，按清单／兼容性设置弹出 UAC 授权；取消授权给出中文失败提示，不提高整个助手的权限。退出命令不自动提权，拒绝访问不触发授权重试。默认请求正常关闭，四秒未退出显示失败；仅显式允许时强制结束。预设原退出参数和策略保留。
- 名称、路径与启动参数编辑前重新核对没有匹配进程；启动／停止中禁止变更列表。beta.9 例外：仅调整超时强制结束选择时允许运行中保存，串行化到原工具的启停锁内；先持久化再更新原实例策略，保留实际状态、失败重试与勾选。保存失败不改变运行策略，不自动发起关闭。失效路径仍保留条目，可修复路径；身份无法确认时保留错误。重复路径及与已定位预设重复时拒绝添加，不允许管理助手自身。
- beta.9 检查关闭窗口消息的实际返回值，Windows 访问拒绝立即提示权限差异，不再伪装成普通退出超时。枚举过程中已消失的窗口忽略，进程身份与句柄复核维持原规则。强制结束同样受 Windows 权限限制，不自动重启／提权助手。
- 保存先落盘，再更新运行注册表；失败保留原运行列表。通用设置保存／恢复默认保留最新自定义列表；增删改即时刷新当前面板，刷新循环使用快照和代次合并，避免列表变化破坏枚举。
- 新程序不自动启动，添加不等于运行。左侧勾选、四类批量动作、A 绿色开关及 B 按钮继续使用统一接口。退出助手保留全部外部程序。

## 验证

配置克隆／JSON／旧配置／损坏条目与保留主题，新增／编辑／重复／失效路径修复／保存失败／运行中移除，真实宿主与编辑器／图标／通用设置草稿合并及窗口重开；专用进程验证原始启动参数、默认不强制和显式强制。测试不控制用户应用。

首版只支持普通 EXE，暂不单独配置启动器和实际监控目标，不加载插件，不安装软件，不添加开机启动或自动重启。beta.15.4的受限米哈游接力适配和显式停止定向授权见[ADR0007](0007-launcher-handoff-and-elevated-stop.md)；不提供任意子进程或通用模糊匹配。
