# 发布与诊断标准

- v0.2 运行入口为 EousAssistant.exe，发布目录／稳定包为 EousAssistant-win-x64，另保留带版本 ZIP 和 SHA-256。项目文件与仓库名保留 EousGate。
- 包含用户说明及许可证，不打包测试数据或个人目录历史。助手及模块设置与 FolderHop 历史保存于新的用户 EousAssistant 数据目录。

- 发布形式为 Windows 11 x64 绿色包；不自动写入开机启动项、不修改默认文件关联。
- 发布前必须完成构建、测试、首版手工验收和依赖检查，并记录版本与日期。
- 诊断默认关闭；开启后只写本机必要信息，不记录文件内容、文件名或完整路径。
- 发布包不得依赖网络、远程图片、远程字体或开发机绝对路径。
- 启动失败、候选发现失败和打开动作失败应能转为用户可理解的反馈；详细异常仅在本地诊断开启时记录。
- 每次发布在日态中记录验证结果、已知限制和回退方式。
