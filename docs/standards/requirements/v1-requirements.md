# 首版需求标准

## 目标

EousGate 是 Windows 11 优先的本地 WPF 工具：用户拖动一个或多个文件靠近主屏幕边缘时显示打开面板，选择软件选项后执行打开动作。

## 必须满足

- 只承诺主屏幕与普通文件；一次拖拽支持一个或多个文件，包含文件夹时整批拒绝。
- 混合文件类型只展示所有文件共同可用的软件选项；选择后只启动一次并按拖入顺序传入全部文件。
- 默认显示前 4 个候选软件，并支持展开查看更多。
- 选择软件后立即打开，不增加确认框。
- `Esc`、面板外松开，或鼠标同时离开触发侧接收条与打开面板并超过自动收起时长，必须取消/收起且不启动软件。
- 无候选、路径失效、权限不足和启动失败必须有可理解反馈。
- 程序只在本机运行，首版不联网、不上传诊断数据。
- 设置中心支持按文件扩展名维护 EousGate 自定义打开方式。该能力只影响 EousGate 的候选列表和打开动作，不修改 Windows 默认应用、文件关联或注册表。
- 接收条支持左侧、右侧、上侧的任意勾选组合；拖拽触发的打开面板以鼠标屏幕位置为锚点显示，并在屏幕边界内自动避让。

## 明确不包含

多显示器、文件夹、收藏排序、自动开机启动、Windows 10 兼容承诺、自动更新和 Shell 插件。

## 变更规则

超出上述范围的需求必须先更新本文件、补充验收条件，并在必要时新增 ADR；不得通过实现细节隐式扩大范围。

术语以 [`CONTEXT.md`](../../../CONTEXT.md) 为唯一语言来源，使用“文件、拖拽会话、打开面板、软件选项、打开动作”等词。
