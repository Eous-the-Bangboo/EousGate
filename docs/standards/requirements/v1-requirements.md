# 首版需求标准

本文件保留 EousGate 首版行为。v0.2 新增统一助手、手动启动的三个独立模块和四种批量操作，详见 [ADR 0004](../../adr/0004-assistant-host.md)；不以本文件旧版单工具边界排除已批准整合范围。

## 目标

EousGate 是 Windows 11 优先的本地 WPF 工具：用户拖动一个或多个文件靠近主屏幕边缘时显示打开面板，选择软件选项后执行打开动作。

## 必须满足

- 只承诺主屏幕与普通文件；一次拖拽支持一个或多个文件，包含文件夹时整批拒绝。
- 混合文件类型只展示所有文件共同可用的软件选项；选择后只启动一次并按拖入顺序传入全部文件。
- 默认显示前 4 个候选软件，并支持展开查看更多。
- 选择软件后立即打开，不增加确认框。
- `Esc`、面板外松开，或鼠标同时离开触发侧接收条与打开面板并超过自动收起时长，必须取消/收起且不启动软件。
- 无候选、路径失效、权限不足和启动失败必须有可理解反馈。
- 文件快开应在普通权限下接收普通资源管理器拖放；助手以管理员权限运行时，启动模块需明确提示 Windows 权限限制和普通重启方法，不能报告可用运行状态。
- 程序只在本机运行，首版不联网、不上传诊断数据。
- 设置中心支持按文件扩展名维护 EousGate 自定义打开方式。该能力只影响 EousGate 的候选列表和打开动作，不修改 Windows 默认应用、文件关联或注册表。
- 接收条支持左侧、右侧、上侧的任意勾选组合；拖拽触发的打开面板以鼠标屏幕位置为锚点显示，并在屏幕边界内自动避让。
- 接收条三侧各自输入起点/终点百分比，默认0–100；左右从工作区上到下，上侧从左到右。允许小数且0 ≤ 起点 < 终点 ≤ 100；保存后更新实际接收范围并可重开读回，非法输入保留草稿且不保存，旧长度/偏移兼容换算。

## 剪贴板网页提示（2026-09-27 增补）

- 2026-10-19：新增可勾选的“连续复制自动打开”，默认关闭，默认连续复制次数为 3，可设 2–10。同一文段相邻两次复制间隔不超过 3 秒，达到次数后使用默认浏览器打开全部不同的 HTTP/HTTPS/www 地址（沿用最多 20 个链接的提取上限）。未达到次数仍提示，达到后收起提示。
- 文段变化、无网页链接、复制间隔超时、模块停止或设置应用后清空临时计数；同一连续序列只自动打开一次。指纹只在内存短时比较，不持久化剪贴板内容。关闭该选项时维持每次复制提示、点击才打开的行为；浏览器打开部分失败时保留失败地址供手动重试。

- 程序运行时监听每次剪贴板文本更新，从文本中提取 HTTP、HTTPS 和 www 开头的网页链接；同样内容再次复制仍须重新提示。
- 主屏侧边显示临时链接提示，点击链接后使用默认浏览器打开；多个链接逐项可选。
- 默认停留 5 秒，可在设置中调为 2–60 秒，并支持关闭检测和选择左/右侧。新复制重置倒计时，悬停或键盘焦点在提示内时暂停计时。
- 提示不抢输入焦点；支持关闭与 Esc。检测仅在本机进行，不联网探测网页、不保留剪贴板历史、不记录文本或网址。
- 剪贴板暂时被占用时短暂重试；关闭检测、暂停或退出时停止监听并收起提示。

## 明确不包含（其他范围）

多显示器、文件夹、收藏排序、自动开机启动、Windows 10 兼容承诺、自动更新和 Shell 插件。

## 外部工具监控（2026-10-16 增补）

- beta.6 支持用户添加、编辑、移除普通 EXE，自动名称／图标、可选参数及持久化稳定 ID；自定义程序复用独立／批量操作与监控。默认只正常关闭，超时强制由用户明确选择；移除和退出助手保留程序进程。详见 ADR 0006。

- 控制面板正常显示或最大化时每两秒刷新外部应用状态；失去焦点继续，最小化、隐藏或关闭到托盘时暂停。无面板不检测，首次打开与恢复立即刷新，暂停保留上次状态。
- 暂停不得停止工具或中断用户已发起的启停与结果确认；退出助手保留外部程序。细节见 ADR 0005。

## 变更规则

超出上述范围的需求必须先更新本文件、补充验收条件，并在必要时新增 ADR；不得通过实现细节隐式扩大范围。

术语以 [`CONTEXT.md`](../../../CONTEXT.md) 为唯一语言来源，使用“文件、拖拽会话、打开面板、软件选项、打开动作”等词。

## 文件快开分类与推荐（beta.12）
- 常见后缀按视频、音频、图片、文档、表格、演示、压缩包、代码与配置分类展示，支持搜索、自定义后缀和已自定义浏览。
- 不配置也自动对实际关联软件排序并收起明确不匹配项；系统默认、用户排序、手动显示和自定义优先，未知软件保留。提供完整关联列表和后缀／整类恢复推荐。
- 切换后缀保留未应用草稿，数量错误阻止切换；应用／保存持久化，取消不提交。
