# 开发标准总览

本目录存放 EousGate 的需求、技术、设计、执行、测试和发布标准。标准用于限制变更范围和定义验收条件，不替代产品设计文档或 ADR。

| 标准 | 文件 | 核心问题 |
| --- | --- | --- |
| 需求 | [`requirements/v1-requirements.md`](requirements/v1-requirements.md) | 这项能力是否属于首版 |
| 技术 | [`architecture/technical-standards.md`](architecture/technical-standards.md) | 代码应该放在哪一层，如何处理系统错误 |
| 设计 | [`design/ui-design-standards.md`](design/ui-design-standards.md) | 界面和交互如何保持一致、可用 |
| 执行 | [`development/execution-standards.md`](development/execution-standards.md) | 如何拆分、记录、审查和回退 |
| 测试 | [`testing/test-standards.md`](testing/test-standards.md) | 如何验证功能和防止回归 |
| 发布 | [`operations/release-and-diagnostics.md`](operations/release-and-diagnostics.md) | 如何安全打包、记录诊断和发布 |
