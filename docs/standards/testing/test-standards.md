# 测试与验收标准

## 助手整合（v0.2）

- 默认脚本包含 `--custom-program-smoke`：添加／编辑／移除即时列表、图标、开关联动、运行中修改拒绝、通用设置草稿合并与重开；基础测试覆盖持久化／坏条目／重复／失效路径修复／保存失败／移除不退出。真实进程回归验证自定义原始参数、默认不强制及显式强制，限专用测试 EXE。

- beta.2 默认脚本新增专用 EXE 的真实进程控制回归；只读 `--external-inspect-smoke`／`--external-monitor-smoke` 可核对已安装应用，不停止用户软件。
- 外部状态监控覆盖外部手动启停、幂等与失败恢复；控制必须限定完整路径、当前用户和会话，退出助手保留外部程序。
- 默认 `--external-monitor-lifecycle-smoke` 用假控制器验证面板显示／失焦持续刷新、无面板／最小化／隐藏／关闭零周期检测、恢复立即刷新、慢检测暂停与恢复合并、启停确认不受影响和退出释放。可选 `--external-monitor-smoke` 验证无面板不检测及显示面板后的已安装程序只读状态；桌面另核对任务栏恢复和托盘重开。

- 生命周期覆盖独立／四类批量操作、空勾选、重复和并发操作、部分失败及原配置保留。
- 默认脚本增加无桌面输入的 Assistant 离屏布局与 FolderHop 重复启停检查。
- `--assistant-host-smoke` 为可选实际宿主检查，先退出旧版和其他助手实例；使用隔离数据并暂停目录采样，检查真实窗口、监听和互斥标记释放。
- 离屏缩放图片不能代替实际监视器 DPI、高对比度、文件拖拽或 Edge 文件对话框跳转验收。

## 基础检查

- beta.15.4 默认增加 `--folder-dialog-smoke` 与 `--launcher-process-smoke`：前者创建真实同进程WPF标准文件选择框，使用受控前台读取器抵抗测试时Windows前台锁，独立观察原生前台窗口、按钮可见/启用，验证点击打开列表、两轮复用及线程清理；后者只控制专用EXE夹具，验证bootstrap接力、持续状态、重复启动幂等、排除游戏路径、拒绝访问授权调度和等权限工作器执行。另对发布EXE验证无效请求退出码2、有效精确夹具关闭退出码0。真实UAC确认、真实启动器退出和实际Edge交互不以此替代。

- beta.15.3：`--file-drop-permission-smoke` 必须先真实调用生产权限检测并与当前Windows令牌比对，再执行提升状态注入测试；只验证注入状态不能代表真实查询成功。可在无原生模块实例冲突时追加`--assistant-host-smoke`，验证生产查询到实际文件快开窗口创建、独立启停与资源清理。

- beta.15.2 基础范围回归覆盖三侧0–100默认、小数与极短范围、非法区间/非有限数值、JSON读回及旧长度/偏移位置迁移。`--file-hop-smoke` 验证非法输入零保存、草稿保留、跨页错误返回文件页签组和独立数值重开；`--window-switching-smoke` 比较真实HWND在0–100、20–80、5–30下的位置及尺寸；`--workbench-smoke` 检查页签文字/间距/祖先裁切并生成默认/最小窗口截图。旧TabPanel模板可复现“tab border must not be clipped by an ancestor”，修复模板通过，证据在work/beta15-tab-baseline.log。

- beta.15.1 默认脚本增加 `--file-drop-permission-smoke`：注入提升权限状态，验证文件快开启动明确失败、重复启停清理、无窗口残留及其他工具状态隔离，不请求 UAC 或触碰用户进程。剪贴板提示核查关闭符号所需尺寸不超过内容区，输出浅深色100/125/150/200%离屏图；真实资源管理器拖放与实际DPI继续现场验收。

- 连续复制自动打开覆盖选项默认关闭、2–10 次设置读回、同文段阈值、全部网址去重、超时和文段变化重置、非链接打断、停止／设置应用清空，以及部分打开失败的手动重试。默认脚本执行 `--clipboard-smoke`，通过合成读取器和浏览器启动器验证快速连续消息不被合并，不修改用户剪贴板或打开真实网页。

- 每个阶段至少执行一次 `dotnet build` 并记录 SDK、目标框架和结果。
- 领域和适配层行为应有自动化测试；新增依赖需记录版本和还原结果。
- UI 行为在无法自动化时使用可重复的手工场景记录。

## 首版验收矩阵

- 启动后托盘出现，桌面无遮挡，可打开设置并退出。
- 执行 `Tests/run-tests.ps1` 时同时验证真实 HWND 的工具窗口样式、首次显示与重显、三侧接收条暂停恢复和位置开关、设置所属对话框及预览例外；可单独运行测试程序的 `--window-switching-smoke`。
- 桌面验收：待机及辅助浮层显示时，Win+Tab、Alt+Tab 和任务栏均无辅助窗口条目；设置窗口可正常切换，所属添加打开方式对话框可正常操作。三侧拖拽、Esc 取消、暂停恢复及剪贴板点击正常。原生样式自动检查不能代替 Shell 实测。
- 一个或多个常见文件靠近主屏边缘时显示打开面板。
- 混合类型只显示共同软件；选中后所选软件只启动一次并接收全部文件。
- 候选超过 4 个时默认显示 4 个并可展开。
- 选择软件成功打开文件并收起面板。
- `Esc`、面板外松开，以及离开触发侧接收条和打开面板超过自动收起时长，都不会启动软件；返回接收条可重新触发。
- 无候选、失效路径、权限不足和启动失败均显示可理解结果并支持取消/重试。
- 浅色/深色、高对比度及 100%/125%/150% 缩放无截断、重叠。
- 暂停阻止新拖拽会话；多屏和文件夹不会产生未定义打开动作。
- 启动和使用期间无网络请求，诊断不记录文件内容。

## 连续复制验证边界（beta.11）
- 合成 WM_CLIPBOARDUPDATE 不等于实际复制源测试；覆盖同序列多通知仅交付一次，新序列相同文本继续交付，停止重启清空序列缓存。
- 可选 --clipboard-real-smoke 使用真实 WPF TextBox.Copy、真实系统剪贴板与生产读取器，只有浏览器启动器替换；默认脚本不修改用户剪贴板。仅支持原剪贴板为纯文本的现场测试，先保存原文本，结束恢复，持锁复查序列防止覆盖用户期间的新复制。富内容直接跳过。
- 本轮 Edge 工具因无法可靠确认网址被停止，微信未操作；二者不得记为验收通过。

## 文件快开推荐（beta.12）
- 基础测试覆盖目录／查询／后缀校验、默认／类型匹配／未知／打包应用、用户排序／隐藏／手动显示与自定义优先。
- 默认 Release 脚本执行 --file-hop-smoke：WPF 分类、搜索、草稿切换、数量校验、应用／读回、整类恢复、写入失败／取消及 A/B 默认／最小尺寸离屏图。测试隔离 JSON，不启动候选软件、不写真实剪贴板或用户配置。
