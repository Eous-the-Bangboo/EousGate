# 测试与验收标准

## 基础检查

- 每个阶段至少执行一次 `dotnet build` 并记录 SDK、目标框架和结果。
- 领域和适配层行为应有自动化测试；新增依赖需记录版本和还原结果。
- UI 行为在无法自动化时使用可重复的手工场景记录。

## 首版验收矩阵

- 启动后托盘出现，桌面无遮挡，可打开设置并退出。
- 一个或多个常见文件靠近主屏边缘时显示打开面板。
- 混合类型只显示共同软件；选中后所选软件只启动一次并接收全部文件。
- 候选超过 4 个时默认显示 4 个并可展开。
- 选择软件成功打开文件并收起面板。
- `Esc`、面板外松开，以及离开触发侧接收条和打开面板超过自动收起时长，都不会启动软件；返回接收条可重新触发。
- 无候选、失效路径、权限不足和启动失败均显示可理解结果并支持取消/重试。
- 浅色/深色、高对比度及 100%/125%/150% 缩放无截断、重叠。
- 暂停阻止新拖拽会话；多屏和文件夹不会产生未定义打开动作。
- 启动和使用期间无网络请求，诊断不记录文件内容。
