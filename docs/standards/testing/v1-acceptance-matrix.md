# 首版验收矩阵

本矩阵把自动化检查和 Windows 手工场景分开记录。手工场景在同一台 Windows 11 主屏幕上执行；每次执行填写日期、构建输出和结果，不把用户文件路径写入日志。

## 自动化入口

在仓库根目录运行：

```powershell
.\Tests\run-tests.ps1
```

脚本会还原测试项目，将主项目和测试项目输出到系统临时目录，然后运行测试程序集。预期结果为构建 0 警告/0 错误，且测试进程返回 0。

## 手工场景

| 编号 | 场景 | 步骤 | 预期结果 |
| --- | --- | --- | --- |
| M-01 | 启动与托盘 | 启动发布或 Debug 程序，观察桌面和通知区域 | 托盘出现；桌面无遮挡；无自动启动项写入 |
| M-02 | 单文件边缘唤出 | 拖动一个常见文件到主屏幕左边缘并保持触发延迟 | 打开面板出现候选软件选项 |
| M-03 | 同类型多文件 | 同时拖动两个同类型文件到接收条并选择软件 | 面板显示文件数量；软件只启动一次并接收两个文件 |
| M-04 | 文件夹拒绝 | 拖动文件夹或文件与文件夹混合到接收条 | 显示不支持提示；不产生打开动作 |
| M-05 | 候选展开 | 对候选超过 4 个的文件触发面板并选择“更多” | 初始显示 4 个；展开后可滚动查看其余候选 |
| M-06 | 成功打开 | 在面板选择可用软件选项 | 文件交给所选软件；面板收起 |
| M-07 | 取消路径 | 面板出现后按 `Esc`，在面板外松开，或离开触发侧接收条和面板超过自动收起时长 | 面板收起；不启动软件；拖拽未松开时返回接收条可重新经过触发延迟显示 |
| M-08 | 失败重试 | 使用失效候选或制造启动失败，再点击“重试” | 显示可理解失败结果；可重试或取消 |
| M-09 | 无候选入口 | 对没有候选的软件类型触发面板 | 显示无候选状态；“选择其他软件”打开 Windows 选择软件入口 |
| M-10 | 暂停 | 从托盘选择“暂停边缘唤出”，再拖动单个文件 | 不创建新拖拽会话；恢复后可再次触发 |
| M-11 | 设置恢复 | 打开设置，修改主题/边缘参数并保存；重开设置后检查 | 修改值恢复；取消编辑不污染已保存值；恢复默认值一致 |
| M-12 | DPI 与主题 | 在 100%、125%、150% 缩放下分别检查设置窗口和打开面板；切换浅色、深色和高对比度 | 文字、图标、按钮无截断或重叠；颜色与系统主题一致 |
| M-13 | 退出 | 从托盘选择“退出” | 窗口和托盘图标消失；进程退出 |
| M-14 | 隐私边界 | 使用程序并检查网络监视与诊断输出 | 无网络请求；诊断不记录文件内容或完整文件路径 |
| M-15 | 自动收起设置 | 在设置中将自动收起时长设为 0、500 和 10000 毫秒，拖拽后离开接收条与面板 | 分别立即、按配置时长和宽限至 10000 毫秒收起；设置重开后值保持 |
| M-16 | 接收条尺寸 | 在设置中为左/右/上侧分别调整长度、宽度和偏移，应用后观察屏幕边缘 | 每侧只覆盖配置后的矩形区域；未覆盖区域可正常点击；拖入接收条仍可唤出面板 |
| M-17 | 混合类型共同软件 | 同时拖动不同类型文件到接收条 | 只显示全部类型共同可用的软件，顺序沿用首个文件类型 |
| M-18 | 混合类型无共同软件 | 同时拖动没有共同软件的不同类型文件 | 显示无共同软件空状态；不显示“选择其他软件”入口 |
| M-19 | 打包应用多文件 | 将多个受支持文件交给 Photos 等打包应用 | 通过文件激活一次交付全部文件；失败不退出 EousGate |
