# 界面与交互设计标准

## 网页快开连续复制设置（beta.10）

- “剪贴板链接”设置新增“连续复制自动打开”复选项，默认关闭；次数输入为 2–10，默认 3。未勾选时次数输入禁用，关闭网页检测时整组选项禁用。
- 明示相邻复制间隔不超过 3 秒、达到次数后打开全部不同的网址，同一连续序列只打开一轮。普通复制和自动打开部分失败仍沿用链接提示，错误时只列出未打开的地址。

## EousAssistant 控制面板（v0.2）

- beta.9 自定义程序运行中可单独保存“超时强制结束”选择；名称、路径和启动参数仍须停止后修改。高级说明提示未保存内容与权限限制。关闭消息被 Windows 拒绝时显示可执行的权限处理说明，保留运行方向以便重试。

- beta.8 开关在确认状态改变时播放滑块位移与轨道渐变；连续状态／能力通知不重启动画，反向切换从当前位置开始。隐藏／卸载释放动画，恢复显示当前终态；系统关闭动画或高对比度时直接显示终态。

- beta.7 使用本地内嵌 Eous 角色图；EXE／窗口／托盘共用多尺寸绿底 ICO，首页与设置页头像按实际背景切换绿底／炭灰底。非Eous原生工具的“＋ 添加程序”使用 120×36 强调色实心按钮，与行内设置操作区分，并保留键盘焦点及高对比度主题资源。

- 自定义监控入口位于非Eous原生工具分组的“添加程序”；行内“设置”进入编辑／移除。高级参数及强制结束默认折叠、默认不强制；提交中禁用重复操作并显示反馈，错误留在表单。名称／图标从 EXE 提取，失败回退为本地图标；增改后滚动显示对应条目，不重新打开面板。

- beta.5 的 A 单个工具使用苹果绿启停开关，替代独立启动／停止按钮；左侧批量勾选、设置及底部批量动作保留，B 不变。开关跟随确认运行状态；处理中保留原位置并转圈、防重复，启动失败回到关闭，停止失败保留开启以重试停止。外部监控状态及能力校验继续生效；支持 UIA Toggle 与键盘，尊重系统动画／高对比度。

- beta.2 按“Eous原生工具”“非Eous原生工具”分组，共用条目操作和一个滚动区域；两组分别展示数量，四个批量按钮作用于整个列表。

- 首页从工具注册目录生成可滚动列表，展示中英文名、图标、说明、勾选、真实运行状态、独立启停及设置。
- 勾选只控制下一次批量操作；四按钮为启动勾选、关闭勾选、全部启动、全部关闭。启动失败在对应条目显示原因。
- 打开助手不启动模块，关闭面板保留运行工具；退出助手才停止全部工具。只有一个助手托盘。
- 主题使用已有本地资源；保留键盘焦点、文字状态和滚动能力，不依赖颜色区分状态。

- 打开面板是临时悬浮面板，不在未拖拽时占用工作区。
- 软件选项使用稳定尺寸的图标 tile；默认 4 个，可展开并在边界内滚动。
- 面板必须提供清晰的选择、取消、无候选、失败和重试状态。
- 取消操作不得产生打开动作；成功打开后面板收起。
- 文案使用 `CONTEXT.md` 的统一术语，避免“方式”“侧栏”等歧义词。
- 跟随系统浅色/深色和高对比度；100%、125%、150% 缩放下文字、图标和点击区域不得截断或重叠。
- 控件需要可键盘操作，图标或不熟悉的操作必须有可读名称或工具提示。
- 不使用网络图片、远程字体或无法在绿色包中加载的资源。
- 边缘接收条、打开面板和剪贴板提示使用原生工具窗口样式，不进入任务栏、Alt+Tab 或 Win+Tab；设置窗口正常参与切换，添加打开方式对话框归属设置窗口且不单独占用任务列表条目。调试打开面板预览保留独立窗口行为。

## 打开面板视觉语言

- 使用单列浮动命令面板，默认宽度约 404 像素；软件选项按行排列，避免方形磁贴造成的拥挤和扫描跳跃。
- 顶部同时显示文件类型、打开面板标题和候选数量，但不显示用户文件名或完整路径。
- 多文件时顶部显示文件数量；同类型显示扩展名，混合类型显示类型数量与“共同软件”，仍不得显示文件名或路径。
- 软件选项由稳定图标区、软件名称、类型说明和打开指示构成；基础状态保持安静，仅在悬停和键盘焦点时显示强调面。
- 面板使用 8 像素圆角、细边框和克制阴影；三色顶轨只用于建立 EousGate 的视觉识别，不扩散为整页渐变。
- 出入场、候选错峰、悬停位移和失败摇动使用同一时长体系，并尊重 Windows 的客户端动画开关。
- 浅色、深色和高对比度必须使用现有主题资源；高对比度下强调轨道回退为系统高亮色。

## 设计中心

- 打开面板设计使用稳定的语义化 ID 持久化，不以显示名称或列表顺序作为设置值。
- `floating-command` 是默认“方案一”，对应单列浮动命令面板；未知或已移除的方案 ID 必须回退到方案一。
- 当前只保留 `floating-command` 单列浮动命令面板，不展示仅有一项的布局选择区；已移除 `compact-list` 和 `icon-grid` 的入口、预览与渲染分支。

## 设置保存与自定义候选

- 底部操作顺序固定为“恢复默认、帮助、取消、应用、保存”。“应用”校验并写入当前设置、立即刷新运行时且保持窗口打开；“保存”复用相同逻辑并在成功后关闭窗口。
- 应用顺序页的自定义候选必须显示“自定义”状态；可用性失效时保留配置并显示“应用已不可用”，但不可启动。
- 自定义打开方式绑定到当前扩展名，只在 EousGate 内生效；删除只移除本地配置，不卸载应用、不修改 Windows 文件关联。

## 鼠标感知与双侧接收条

- 接收条位置由设置中心控制，左侧、右侧、上侧分别使用复选框，可任意组合；关闭的一侧不得拦截拖拽输入。
- 打开面板以触发时鼠标位置为锚点，靠近左侧时向右展开，靠近右侧时向左展开，并在工作区边界内保持完整可见。
- 软件选项在鼠标悬停、键盘焦点和按下状态下必须有明确高亮，不改变候选排序或打开动作。
- 面板显示后，触发侧接收条和打开面板共同构成鼠标安全区域；鼠标离开两者超过设置的自动收起时长后收起面板，但当前拖拽仍可返回接收条重新触发。
- 多文件没有共同软件时显示明确空状态且仅允许取消；不得打开只能处理单文件的系统“选择其他软件”入口。
- 左、右、上侧接收条分别配置长度、宽度和偏移；长度按边长百分比，宽度按工作区短边百分比，长度不足整边时默认居中。

## Windows 11 材质

- beta.4 的 A 依据 Figma 7:7／7:297／7:212：68 px 工具行与固定底栏；外观设置三卡片与即时预览；打开面板使用 36 px 文件标识、60 px 软件行和单色强调轨道。B 保持原样。
- A 入场一次播放，使用 cubic-bezier(.2,0,0,1)；以 160 ms 为参照按用户动效时长缩放；关闭客户端动画或高对比度时直接显示终态。取消／隐藏／关闭释放动画，新的会话不得被旧退出回调隐藏。A 失败使用文字与重试反馈。

- 默认 `win11-mica` 皮肤升级为 A 原生 Fluent，保留既有配置 ID；`focus-dark` 为 B 深色效率。仅提供 A/B 两项；旧 `acrylic-glass`／`clear-surface` 配置在读取与保存时回退为 A。
- A 遵循独立主题设置；B 固定深色并保留用户原主题值，切回 A 恢复其效果。高对比度始终覆盖两种皮肤。
- 强调按钮文字使用 `PanelOnAccent` 语义色；B 的浅薄荷背景必须使用深色文字。
- 外观页选择只改变设置窗口的局部预览，应用／保存后才更新全局与持久化；预览不执行真实文件打开动作。

- 设置中心和自定义应用编辑窗口优先使用 Windows 11 DWM Mica 系统背景，同时保留主题底色作为客户端安全兜底，避免透明窗口在特定 DWM 组合下黑屏。
- Windows 旧版本、DWM API 不可用或高对比度模式下自动回退到现有主题背景，不得影响窗口可用性和可读性。

## 文件快开软件选项（beta.12）
- 分类列、可搜索后缀和软件列表沿用现有 A/B 主题与键盘焦点；推荐理由使用文字，未推荐项默认折叠且可勾选恢复。
- 切换前保留草稿，浏览不固定智能排序。后缀／整类恢复只重置排序和隐藏，保留用户添加和数量覆盖；提交失败保留编辑并显示错误。

## 模块工作台（beta.13，优先于上文旧版主页规则）
- 采用已确认 02 方向：三张原生工具横排卡、外部程序表格、固定底栏、自绘标题栏；固定炭灰／黄绿，A/B 用于打开面板等辅助浮层。
- 主列表隐藏选择控件和勾选操作，保留全部启停；请求位置即时切换，文字维持真实过渡状态，失败按实际状态回弹，忙碌防重复。
- 全部工具设置采用所属工作台遮罩、缩放淡入／收回、外部点击和 Esc 关闭；内部点击不关闭，异步保存保护，保存失败保留输入。
- 文件分类推荐设置保留完整内容，默认后缀 18 项可展开全部，候选与后缀只使用外层页面滚动；运行统计不重复，完整说明折叠按需阅读。

## 第2轮确认设计（beta.14，优先于旧版布局描述）
- 用户确认后以第2轮稿同步：原生模块184px，不显示英文内部名称；状态与启停就近并提高文字权重。真实错误可使卡片自适应增高，不裁切。
- 网页快开两组设置共享阅读面，次数与间隔就近，规则折叠；默认关闭与禁用逻辑不变。
- 软件选项当前后缀固定在软件列表上方，“更换后缀”按需展开分类/搜索；只保留正文一处滚动。软件行提供排序按钮，点击排序不改变可见勾选。候选数量以真实发现为准。
- 恢复操作明示“全部设置”“整类××推荐”“此后缀推荐”，不以相同的泛化文案隐藏作用范围；帮助与现有配置能力保留。
- 工作台模式只播放所属遮罩的一套收放动画，设置自身不再叠加入场。


## 03圆角工具清单（beta.15，优先于旧版视觉描述）

- beta.15.2：文件设置两个横向页签按内容自然排布，文字、间距、选中背景和焦点边框不得被裁切。接收条三侧分别显示起点%、终点%、宽度%，说明方向与默认0–100；错误在范围控件附近显示，保留输入，不以旧长度/偏移术语继续暴露配置。
- 依据2026-10-20新确认原型：980×700默认窗口，184px侧栏与六行开放清单；900×600可滚动，角色完整缩小，不设头像或姓名区。
- 暖白/鼠尾草绿，橙色主操作；所有自绘控件使用12px圆角。原画Eous与原Eous图标均内嵌，格式转换不改变RGBA像素。
- 设置为右侧720px抽屉，文件设置用触发与面板/打开方式横向页签，正文统一24px锚线；关于页只读。现有高级能力保留按需展开，恢复/帮助等操作继续可达。
- 通用与文件/网页设置关闭时保护未应用修改；保存失败保留输入。程序异步保存期间同时保护抽屉与所属主窗口。外部控制和配置范围不变。
- 默认辅助面板跟随助手；保留旧A/B配置ID及始终深色选项，选择过程不提前写入配置。WinForms目录控件按逻辑DPI缩放，截图比较必须统一DPI基准。
