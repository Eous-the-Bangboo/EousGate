# EousAssistant · Eous 助手

请先从托盘退出旧助手，再解压完整文件夹运行 EousAssistant.exe，保留同目录运行时依赖。本程序是 Windows 11 x64 绿色版，不需要预先安装 .NET Runtime。

请普通双击启动助手。以管理员身份运行时，Windows 会阻止普通资源管理器向助手拖入文件，文件快开会显示权限原因并保持未启动。请从托盘退出后普通双击重开；若仍出现授权弹窗，取消快捷方式“高级”或 EXE“兼容性”中的管理员运行选项。外部程序需要管理员权限时，助手可单独请求授权。

## 控制工具

文件快开 → 设置 → 触发与面板：左侧、右侧、上侧各自输入接收条“起点 %”和“终点 %”。左右侧从工作区顶部向底部计算，上侧从左向右计算；默认 0–100 铺满整条工作区边缘，20–80 只保留中间 60%。允许小数，须满足 0 ≤ 起点 < 终点 ≤ 100；点“应用”或“保存”后更新。宽度仍单独设置。旧版长度与偏移会换算为原来的实际覆盖范围。

- EousFileHop／文件快开：拖文件到主屏幕左、右或上侧，选择软件打开。
- EousWebHop／网页快开：复制网页链接，从侧边提示点击打开。
- EousFolderHop／文件夹快跳：记录系统资源管理器目录，在文件对话框右下角选择最近文件夹，或按 Ctrl+Alt+J。

打开助手后，三个原生模块均未运行，外部程序显示当前真实状态。主页使用两组工具清单：点击开关立即切换请求方向，同时显示启动中／停止中；后台确认成功后保持，失败则回弹并显示原因。灰色为关闭，绿色为开启。

主页暂时隐藏批量勾选，保留独立开关与右上角“全部启动／全部关闭”。侧栏与行尾进入设置，右侧抽屉可点外部、关闭按钮或按 Esc 收起。通用及文件/网页设置有未应用修改时，可保存、放弃或继续；保存中不可误关，失败会保留输入。

beta.15 使用03圆角清单与侧栏原画Eous。软件选项先显示当前后缀与软件列表，点击“更换后缀”再展开分类与搜索；列表行内箭头调整顺序，不改变勾选。恢复按钮明确区分全部设置、整类推荐和此后缀推荐，点击应用或保存后生效。

关闭面板仍保留已启动工具，点击托盘图标可返回。托盘“退出助手”会停止原生工具并保存数据，外部软件继续运行。不自动设置开机启动。

## 旧程序与数据

请先从托盘退出旧 EousGate 和旧 FolderHop，再启动对应模块。助手只显示冲突提示，不强行结束旧程序。

旧 EousGate 配置会在首次启动时复制迁移。旧 FolderHop 历史需在“文件夹快跳 → 设置 → 导入旧 FolderHop 数据”中选择旧目录的 Data/history.json。原程序和原数据不修改；新数据放在当前用户的 LocalAppData/EousAssistant 目录。

## 网页快开：连续复制直接打开

先启动网页快开，在“网页快开 → 设置”勾选“连续复制自动打开”，填写次数并应用／保存。默认不勾选；次数默认为 3，可填写 2–10。

复制同一文段达到次数后，会用默认浏览器打开其中全部不同的网址，不必点击提示。相邻两次复制间隔不超过 3 秒；更换文段、复制无链接内容或超时会重新计数。同一连续序列只打开一轮，继续复制不会重复开标签。部分地址打开失败时，提示中只留下失败地址，点击可以重试。

取消勾选后恢复每次复制提示、点击打开。停止模块或应用设置会清空临时计数，不保存剪贴板内容或网址历史。

## 文件夹快跳

启动后用系统资源管理器正常浏览目录；打开、保存、上传等标准 Windows 文件对话框出现时，通过右下角最近文件夹按钮或 Ctrl+Alt+J 跳转。选择窗口支持搜索、收藏与当前打开目录。设置可暂停记录、隐藏按钮、清空普通历史并保留收藏。

目录采样约 0.75 秒一次，快速略过的目录可能漏记。虚拟目录、自定义文件选择器和管理员权限程序不保证支持。快捷键被占用时使用面板或辅助按钮。

软件完全在本机运行，不上传文件、不读取文件内容、不保留剪贴板历史。文件夹工具启动后会保存本地目录历史，最多 200 条普通记录，收藏不受限制。诊断默认关闭且不记录路径和内容。

## 非Eous原生工具

米哈游启动器可继续选择安装根目录的 `launcher.exe`；助手会识别同一安装目录版本文件夹中的实际 `HYP.exe`，显示真实运行状态。启动器右上角“×”可能只缩到托盘；若需助手彻底退出它，请在该条目“设置 → 高级设置”勾选“正常关闭超时后，允许强制结束程序”并保存，再停止。关闭高权限程序时会单独请求Windows授权，取消授权会保持运行；助手本身仍可普通权限运行。只控制核对过的启动器进程，不按进程树结束已启动的游戏。

主界面下方列出 Ditto、Everything、无线麦 Sayall，支持独立启停，右上角全部启动／关闭同时作用于两组工具。面板正常显示或最大化时每两秒更新实际运行状态，切到其他窗口后继续；最小化、隐藏或关闭到托盘后暂停，恢复时立即刷新。暂停期间保留上次状态，软件继续运行，已发起的启停仍确认结果；已经运行的程序不会再开一份。

设置可自动定位或选择对应 EXE。控制仅针对当前用户、当前会话及同一路径的应用进程，Everything 索引服务保持运行；Sayall 同路径辅助进程计入同一工具。停止先请求正常退出，无响应时结束目标进程；退出助手会保留外部软件。

## 自定义监控程序

在首页“非Eous原生工具”右侧点击“添加程序”，选择普通 EXE。名称和图标自动读取，名称可改；高级设置可填启动参数（含空格的参数用双引号）和选择“正常关闭超时后，允许强制结束”。默认不勾选此选项。

添加后不会自动启动；条目参与实际状态监控、独立开关和批量操作。在条目“设置”编辑或移除；修改名称、路径及启动参数前需停止程序，失效路径可重新选择。运行中可单独调整“正常关闭超时后，允许强制结束程序”并保存，其他字段须保持原值；保存后重新点击开关才会再尝试关闭。移除仅取消管理，不关闭或卸载软件。重复路径及已管理的预设会提示。仅支持 EXE，不单独配置启动器与监控目标，不自动重启崩溃程序。

默认先请求正常关闭，四秒未退出显示失败并保持运行方向；可以自行完成保存和退出后等待状态刷新，或明确开启允许强制结束后再停止。面板最小化／关闭时仍暂停周期监控，退出助手保留外部程序。

LiteMonitor 等管理员权限程序不能由普通权限助手关闭；强制结束选项也无法绕过 Windows 权限。若提示 Windows 拒绝关闭，可从该程序自身菜单退出；或先从托盘退出助手，再右键 EousAssistant.exe 选择“以管理员身份运行”后重试。助手不会自行提高权限。

若程序要求管理员权限（例如部分 TrafficMonitor 版本或启用了“以管理员身份运行”的兼容性设置），点击启动时会由 Windows 弹出 UAC 授权提示。允许后助手重新检测实际进程；取消授权会显示中文提示，可以重试。助手本身保持原权限。管理员权限程序可能无法被普通权限助手关闭，可从该程序自行退出。授权使用另一管理员账号时，该账号的进程不属于当前用户的监控范围。

## 外观皮肤

通用设置可选择系统／浅色／深色，调整动效与文字大小，应用或保存后生效。助手采用03暖白与鼠尾草绿方向，所有主题保留相同清单结构和圆角语言。

展开“辅助面板外观”，可选择“跟随助手”或“始终深色”，并查看文件打开面板的预览。原A/B配置ID继续兼容；选择过程不提前写入配置，取消保留已应用的外观。

版本：0.2.0-beta.15。真实监视器DPI/高对比度、Edge对话框和完整文件拖拽仍需桌面复测。

## 文件快开：常见后缀与智能推荐

在“文件快开 → 打开方式”点击“更换后缀”，选择视频、音频等分类，再点击常见后缀。也可搜索或输入其他后缀并按 Enter。默认已按系统默认应用和类型匹配推荐，无需每种类型都设置。

特殊偏好可勾选／取消勾选软件、上移／下移、添加自定义应用，或展开单独显示数量。打开“显示其他关联软件”可查看并启用未推荐项。切换后缀保留本次草稿，最后点击应用或保存；取消不提交未应用的修改。

想重新自动优化，使用“恢复此后缀推荐”或选中文件分类后“恢复整类推荐”。它们保留添加的软件和显示数量，只重置排序与隐藏。原有手动排序不会被新推荐覆盖。

## 模块工作台外观

助手主界面与设置采用已选定的03圆角工具清单。原画Eous融入侧栏，较小窗口会完整缩小角色；六项工具按固定状态和操作列排列。
