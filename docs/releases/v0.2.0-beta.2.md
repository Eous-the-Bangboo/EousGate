# EousAssistant v0.2.0-beta.2

日期：2026-10-16。

## 新增

- 首页分为“Eous原生工具”和“非Eous原生工具”。
- 接入 Ditto、Everything、无线麦 Sayall 的真实状态监控、独立启停及路径设置。
- 四个批量按钮覆盖原生与外部工具，运行中的应用不会重复启动。
- 外部状态每两秒刷新；助手退出保留外部软件。
- Everything 只控制当前用户桌面应用，保留索引服务；Sayall 的同路径辅助进程计入同一项。

## 验证

- Release 构建：0 警告、0 错误；64/64 自动化回归通过。
- 分组界面：各三项、四类批量操作、最小尺寸、浅深色及 100%/125%/150% 离屏输出、外部列表滚动通过。
- 专用测试进程：主／辅助分组、重复启动幂等、正常退出指令、后备终止、创建时间与会话校验、同名不同目录隔离通过。
- 本机只读定位：Ditto 1 个当前会话进程、Everything 1 个桌面进程（服务排除）、Sayall 2 个同路径进程。
- 实际宿主定时监控：三项显示运行中、原生模块没有自动启动，没有对用户软件发送启动／停止命令。
- 退出助手仅处理原生模块的策略已用模拟控制器验证。

真实应用没有在本轮被重启或强制停止；具体版本的退出保存行为、Sayall 录音中退出等情况尚未现场测试。上一版的 Edge 导航和实际多 DPI 等桌面验收限制继续保留。

## 使用

关闭旧版助手后运行新版 EousAssistant.exe。外部工具若未被定位，在该行设置中选择对应 EXE；已有设置与历史继续保留。停止无响应时会结束该路径的应用进程，操作前请完成该软件当前任务。退出助手不代替“全部关闭”。

## 复测命令

```powershell
.\Tests\run-tests.ps1 -Configuration Release
dotnet "$env:TEMP\EousGate-test-Release\tests\EousGate.Tests.dll" --external-inspect-smoke
dotnet "$env:TEMP\EousGate-test-Release\tests\EousGate.Tests.dll" --external-monitor-smoke
.\publish.ps1
```

前两项外部软件检查为只读，不要求停止现有软件；默认测试脚本的真实进程操作仅作用于专用测试 EXE。发布包不包含这三个软件、用户配置或应用数据。
