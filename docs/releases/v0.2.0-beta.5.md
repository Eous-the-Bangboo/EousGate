# v0.2.0-beta.5 · 苹果绿启停开关

A 首页每个工具的启动／停止合并为苹果绿圆形滑块开关。开启为绿色、滑块靠右；关闭为灰色、滑块靠左。左侧勾选仍只选择批量操作对象，设置和底部四个批量按钮保留；B 使用原有按钮。

- 开关由真实工具状态驱动，点击只是发送启停请求。处理中保留上一次确认位置并显示转圈，禁止重复点击；成功后滑动到新位置。
- 启动失败保持关闭并允许重试；停止失败保留开启方向以重试停止。外部进程仍在运行时保持开启；手动启动或退出由原监控更新开关。
- 继续使用实际启停能力校验；未检测、路径不可用或无对应能力时禁用。错误仍在工具行展示。
- 原生 ToggleButton 鼠标与 Space 操作；自定义 UI Automation Toggle peer 发送同一个启停请求，读回确认状态。转场遵循用户动效时长；关闭系统动画或高对比度时直接切换，高对比度使用系统色。
- 没有更改进程控制、轮询生命周期、用户配置或退出策略。测试仅控制假工具／专用测试进程。

验证包含 66 项基础回归、UIA 操作、延迟启停／防重复、启动失败、停止失败、外部状态同步、四类批量按钮、浅深主题和离屏缩放。B 首页及设置截图与原基准一致。实际显示器 DPI、高对比度桌面和完整拖拽仍沿用 TODO-025；日志与交付校验见 [2026-10-16](../dev-status/2026-10-16.md)。
