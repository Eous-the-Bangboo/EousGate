# v0.2.0-beta.14 · 第2轮设计同步

用户确认第2轮模块工作台设计后，本版同步到实际 WPF。原生卡片收紧至184px，去掉英文内部名称，强调各工具运行状态；保留三卡横排、外部表格、独立与全部启停。

网页快开设置改为两组平面设置，次数和3秒连续间隔就近呈现，完整规则按需展开。连续复制自动打开仍默认关闭、默认3次、可设2–10次，达到后打开全部不同网址。没有改变系统剪贴板计数或浏览器启动逻辑。

软件选项将当前后缀固定在列表上方；分类与后缀搜索由“更换后缀”按需展开。去掉第二列常驻分类和层层嵌套容器，完整候选共用一个滚动区；软件行提供上移/下移，排序不改变勾选状态。恢复入口区分“此后缀推荐”“整类推荐”“全部设置”，仍保留自定义软件与显示数量的原有规则，应用/保存后才生效。帮助入口和真实应用发现保留。

添加程序表单缩短留白，复用原生 EXE 选择器、名称读取和真实保存。失败提示说明本次动作失败、输入保留，不再让场景注入文字充当交付截图的错误示例。保存中继续防误关；普通关闭与收回、点击外部、Esc、失败回弹沿用统一原生实现。工作台弹窗只播放一套收放，避免设置本身与遮罩重复入场。

验证：完整 Release 基础76项及所有WPF、剪贴板、窗口切换、A/B预览、开关、工作台、定制程序、监控与专用真实进程回归通过。剪贴板验证的固定时点断言改为等待可观察的收起状态，并在最终完整回归之外单独重复两次。工作台开关与设置连续三轮；软件行排序、草稿、保存读回和失败保留检查通过。截图来自实际WPF隔离窗口，原生动画生成时间戳帧与GIF，不称为桌面录屏。

独立视觉评审按已确认设计对照当前WPF截图，不打分；报告随包交付。不同候选数量、帮助入口、文件夹专属设置及真实错误原因沿用产品能力，不以示例数据替换。实际显示器DPI、高对比度和微信/Edge真实连续复制现场验收沿用原待办。
