# EousGate v0.1.0-beta.3

新增剪贴板网页链接提示。

## 新功能

- 复制含 HTTP/HTTPS 或 www 链接的文本时，从主屏幕侧边弹出提示；点击用默认浏览器打开。
- 重复复制相同内容也会再次显示并重置计时。
- 默认停留 5 秒；在“设置 → 剪贴板链接”中可设置 2–60 秒、左/右侧和开关。
- 鼠标悬停或键盘操作时暂停收起；多个链接分别可选。
- 本机读取，不保存剪贴板历史，不记录链接；托盘暂停可同时暂停提示和边缘唤出。

## 下载与运行

下载并解压 `EousGate-v0.1.0-beta.3-win-x64.zip`，运行其中的 `EousGate.exe`。包含运行时，无需预装 .NET；更新前请退出旧版。
