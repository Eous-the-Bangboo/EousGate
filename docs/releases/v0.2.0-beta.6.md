# v0.2.0-beta.6 · 自定义程序监控

在首页“非Eous原生工具”右侧点击“添加程序”，选择普通 EXE。名称和图标从文件读取，名称可改；高级设置可填写启动参数，并选择是否允许正常关闭超时后强制结束。

- 添加、编辑和移除即时生效、保存并可重开恢复；条目设置可编辑或移除。重复路径会提示，运行中需先停止再修改；失效路径可重新选择。
- 自定义程序与三个预设一样支持实际进程状态、独立启停和四类批量动作，A 使用绿色开关，B 保留按钮。添加不会启动程序，左侧勾选仅用于批量选择。
- 默认只请求正常关闭；未退出时显示失败并保留运行状态，开启“允许强制结束”后才执行后备终止。移除条目和退出助手均保留外部程序，不卸载或删除文件。
- 监控仍只在面板显示期间每两秒执行，最小化／隐藏／关闭后暂停，恢复立即刷新。完整路径、用户、会话、固定句柄与创建时间校验继续生效。
- 旧配置兼容；通用设置草稿保存不会覆盖新增程序。无新增外部依赖、联网、开机启动或崩溃自动重启。

验证覆盖 68 项基础回归、新增真实宿主／编辑器、绿色开关、图标、保存失败与草稿合并，以及专用测试 EXE 的参数／默认正常关闭／允许强制分支。实际 DPI、高对比度桌面和完整拖拽仍沿用 TODO-025。完整结果和包校验见 [开发日志](../dev-status/2026-10-16.md)，设计决策见 [ADR 0006](../adr/0006-custom-program-monitoring.md)。
