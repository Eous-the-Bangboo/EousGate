# v0.2.0-beta.10 · 网页快开连续复制

“通用设置 → 剪贴板链接”新增可勾选的“连续复制自动打开”，默认关闭；默认连续复制 3 次，可填写 2–10 次。启用后连续复制同一文段达到次数时，使用默认浏览器打开文段内全部不同的网址，无需点击提示。

相邻复制间隔不超过 3 秒；文段改变、复制非链接、超时、模块停止或应用设置时重新计数。同一连续序列仅自动打开一轮，不因继续按复制而重复开标签。提取沿用最多 20 个 HTTP/HTTPS/www 链接，保留有效路径及查询参数。

快速复制通知改为优先即时读取，剪贴板忙碌时保留原短暂重试。计数只保留内存指纹，不持久化剪贴板文段。部分浏览器启动失败时，链接提示仅保留失败地址供手动重试，成功地址不重开。

旧配置自动保留“连续复制自动打开”关闭。未勾选时仍是每次复制重新提示、点击才打开。其他原生与外部工具、皮肤和运行开关保持既有版本行为；本对话中的 HTML 设计改进尚未移植到 WPF。

验证及构建记录见 `docs/dev-status/2026-10-19.md`。
