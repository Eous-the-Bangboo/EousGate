# v0.2.0-beta.15.1 · 2026-10-20

beta15 两项用户反馈的修复版。

后续已知问题：本版新增的权限检测缺少令牌Duplicate权限，真实启动文件快开可能报“拒绝访问”；此前模拟状态回归未覆盖实际查询。该问题由beta.15.3修复，请使用后续版本。

- 网页提示右上角“×”恢复完整显示：关闭按钮覆盖文字按钮的横向内边距，保持原有点击范围、工具提示与辅助功能名称。
- 用户确认原助手以管理员身份运行；普通资源管理器无法跨 Windows 权限边界向该进程进行 OLE 文件拖放。修复版在启动文件快开前检测并明确显示原因、回弹失败状态；从托盘退出后普通双击启动助手，再启用文件快开。外部程序仍可单独授权。
- 本版不提供管理员模式下接收普通资源管理器拖放的跨权限代理。

验证：.NET SDK 8.0.424；完整 `publish.ps1` Release 流程通过，76/76 基础测试、文件快开设置、剪贴板消息、窗口样式、助手/工作台、自定义程序、监控生命周期和专用进程回归通过；新增 `--file-drop-permission-smoke` 验证权限失败可见、重复启停、零窗口残留与其他工具状态隔离。构建零警告零错误。

关闭按钮通过实际内容尺寸核查；浅深色 100/125/150/200% 离屏图已生成，人工查看浅色150%与深色200%确认符号完整。离屏图不代表实际监视器DPI验收。2026-10-20 用户在 beta15 普通启动后反馈“普通启动后已恢复”，本次拖拽故障现场复测通过，确认与管理员权限隔离相关；该反馈不代表完整拖拽矩阵或 beta.15.1 管理员提示的现场验收。
