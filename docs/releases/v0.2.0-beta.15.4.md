# v0.2.0-beta.15.4 · 2026-10-20

修复米哈游启动器接力后的运行状态与停止流程，以及助手自带文件选择框中的快跳按钮闪烁。

- 用户添加的根目录launcher.exe只负责启动，实际常驻的是数字版本目录HYP.exe；本版保留原配置入口，自动核对同安装根目录、同发布者的HYP进程。继续验证完整路径、当前用户/会话与进程创建时间；排除游戏、Helper及任意进程树。
- 用户确认启动器“×”只缩到托盘。设置页说明这一行为并展开高级项，用户需要彻底退出时勾选“正常关闭超时后，允许强制结束程序”。默认不勾选、不擅自变更已有策略。
- 实际HYP文件清单为requireAdministrator；显式停止返回访问拒绝时，助手可通过Windows授权运行短时定向关闭工作器，主助手保持普通权限；取消后保留程序状态和重试。工作器不接受任意命令、不启动目标软件，复核并固定原进程身份后执行，完成即退出。详见[ADR0007](../adr/0007-launcher-handoff-and-elevated-stop.md)。
- 原快跳按钮与WPF文件选择框共享UI线程时反复激活/隐藏；改为独立STA按钮线程，禁止鼠标激活，点击通过宿主消息队列打开列表，关闭模块等待线程释放。历史与Picker仍由原宿主管理。

验证：SDK8.0.424，`publish.ps1`默认完整Release流程通过，81/81基础及全部默认集成回归通过，0警告0错误。

- 真实模态复现：原实现采样显示按钮成为前台与隐藏反复交替（43/47次），见`work/beta15-folder-dialog-baseline.log`。修复版用真实同进程WPF标准文件选择框和受控前台读取器，两轮各80个稳定样本均可见/启用，按钮未成为前台；点击可打开对应列表，复用与释放通过，见`work/beta15-folder-dialog-fixed.log`及最终发布日志。Windows前台锁会阻止测试应用抢占当前用户前台，因此不将受控读取器测试标为人工Edge/桌面全场景验收。
- 真实启动器只读检查：匹配到1个HYP.exe、无检测错误；未停止用户启动器或游戏。
- 专用夹具：bootstrap退出后状态仍运行、重复启动不多开、停止限定目标、排除games下同名进程、拒绝访问触发窄授权调度、等权限工作器实际关闭通过。
- 发布EXE入口：无效请求返回2；有效固定身份的隐藏夹具关闭并返回0；没有创建主界面或接管单实例，未弹UAC，见`work/beta15-launcher-worker-entry.log`。
- 本轮未实际确认用户电脑UAC，也未终止真实启动器；用户按已有设置显式允许强制结束后复测。此前DPI/完整桌面矩阵沿用原验收边界。
