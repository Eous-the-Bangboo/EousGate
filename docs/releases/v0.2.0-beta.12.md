# v0.2.0-beta.12 · 文件快开分类与智能推荐

日期：2026-10-19。包含 beta.11 的剪贴板序列号去重修正；网页快开的真实 Edge／微信现场复制限制沿用 beta.11 记录。

文件快开设置沿用 A/B 主题，用文件分类、后缀列表和软件列表逐层浏览，代替只能手工输入后缀的入口。视频、音频、图片、文档、表格、演示、压缩包、代码与配置包含常见后缀，另有全部常见和已自定义。支持搜索、回车载入其他后缀、空结果提示；按钮和后缀列表支持键盘操作。

所有后缀默认使用本地智能推荐，不必先逐个配置。只对 Windows 实际发现的关联软件排序：用户排序优先，其次系统默认、自定义应用、专业播放器／类型匹配、Shell 推荐和其他关联。根据已知 EXE／包身份判断明显不匹配的组合并默认收起；不凭翻译名称或路径目录猜测未知软件，不自动修改 Windows 默认关联。用户选择的系统默认、自定义应用和手动显示始终优先。

“显示其他关联软件”可查看包括未推荐在内的完整列表并勾选启用；保留显示数量、隐藏、上移／下移、添加及删除自定义。切换后缀前校验并保留当前草稿，应用／保存后统一持久化；无效数量阻止切换，取消丢弃尚未应用的修改。单后缀／整类恢复推荐只清除排序与隐藏，保留添加的软件和显示数量。浏览不会自动固定推荐顺序。已存在的自定义顺序保留，需要重新自动优化时点击恢复推荐。

设置写盘失败在底部和当前软件设置区域显示错误并保留编辑内容；成功应用后清除错误。
