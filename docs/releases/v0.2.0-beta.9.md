# v0.2.0-beta.9 · 2026-10-19

- 本机只读确认 LiteMonitor 为管理员权限、助手为普通权限。LiteMonitor 官方清单也指定 `requireAdministrator`。Windows 不允许普通权限进程向更高权限进程任意发送窗口消息；原关闭逻辑未检查返回值，四秒后误显示普通超时。
- 检查窗口关闭消息的返回值及错误码；访问拒绝提示从程序自身退出，或先退出助手后以管理员身份重开再重试。退出的窗口忽略，完整路径／当前用户／会话／创建时间及固定句柄保护继续生效。
- 自定义程序运行中可单独修改超时强制结束选择；持久化成功后更新原实例，保留状态、失败重试与勾选。不自动关闭或提权；强制结束也受 Windows 权限限制。
- 名称、路径与启动参数仍须先停止再修改。保留默认只正常关闭、移除不退出及退出助手保留外部程序的行为。

依据：[LiteMonitor 清单](https://github.com/Diorser/LiteMonitor/blob/master/app.manifest)、[PostMessageW 权限规则](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-postmessagew)。验证见 [当日日态](../dev-status/2026-10-19.md)。
