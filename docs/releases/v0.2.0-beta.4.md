# v0.2.0-beta.4 · A 方案与动效

设计来源：[Figma A](https://www.figma.com/design/TcXTuFPrFZUWRognzfx1Rf?node-id=7-2)。实际实现为 WPF，无新增依赖、远程字体或网络图片。

- 首页：68 px 基础工具行，六项在默认窗口内可见；保留原生／外部两组、独立操作及四项批量操作，底部固定通用设置入口。失败信息可撑高条目并滚动。
- 外观页：皮肤、主题与动效、阅读与反馈三张卡片；实时预览只作用于设置草稿，应用／保存才更新运行时。动效时长仍为 80–600 ms 数值设置。
- 打开面板：36 px 文件标识、60 px 软件选项、简洁页脚；软件名、图标、文件类型、数量及状态来自实际数据。保留展开、取消、无共同软件、失败与重试。
- A 动效使用 Figma 的 cubic-bezier(.2,0,0,1) 与相对时间；以 160 ms 参考缩放到用户原配置。界面入场只播放一次；面板从触发侧滑入，消失时阻止点击，重开取消旧退出回调。系统关闭客户端动画或启用高对比度时直接呈现完整状态。
- Figma 的云端 Noto Sans SC 为设计预览替代；应用继续使用 Segoe UI Variable Text / Microsoft YaHei UI。窗口标题栏继续使用系统原生控件。B 保留已有视觉和交互样式。

自动验证与包校验结果见 [当日日志](../dev-status/2026-10-16.md)。离屏缩放与原生窗口自动检查不能代替实际显示器 DPI、高对比度桌面及完整文件拖拽验收；沿用 TODO-025。
