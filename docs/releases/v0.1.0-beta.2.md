# EousGate v0.1.0-beta.2

修复拖动图片并选择系统“照片”后，错误打开资源管理器的问题。

## 修复内容

- 从 Windows Shell 读取真实应用标识，正确区分“照片”等显示名称与调用目标。
- 使用所选应用的 Shell 文件关联处理器打开图片，兼容本机新版 Photos。
- 删除错误的 Explorer 回退；打开失败会报告失败，不再误报成功。
- 多文件一次性交付所选应用，并在调用前检查应用是否支持整个文件集合。
- 保留已有候选排序、隐藏设置和自定义软件配置。

## 下载与运行

1. 下载 `EousGate-v0.1.0-beta.2-win-x64.zip` 和 `.sha256` 校验文件。
2. 从托盘退出旧版 EousGate，将新包解压到独立文件夹。
3. 运行新目录中的 `EousGate.exe`；已有本机设置会继续使用。
4. 若已有桌面快捷方式，将目标改为新目录的 `EousGate.exe`。

## Beta 限制

- 支持 Windows 11 x64、主显示器；不支持文件夹、多显示器边缘、自动启动和自动更新。
- 未进行数字签名，Windows 可能显示 SmartScreen 提示。请从本仓库下载并核对 SHA-256。
- 尚未回放完整鼠标拖拽手势；其他 Windows/Photos 版本、干净机器启动、DPI 与高对比度仍需更多测试。
