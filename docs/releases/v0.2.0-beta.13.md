# v0.2.0-beta.13 · 模块工作台

本版将已确认的「02 · 模块工作台」从对话中的 HTML 原型移植到实际 WPF 桌面程序。主页使用炭灰表面、黄绿色强调和 Eous 头像；三个原生模块横排，外部程序以表格呈现。默认 1040×820，较小工作区自动适配并允许内部滚动，标题栏支持拖动、最小化、最大化／还原和关闭面板。

所有工具使用同一个即时开关：点击后立刻转向请求位置，真实状态文字继续显示启动中／停止中，后台确认成功后保持，失败时按实际进程状态回弹并保留错误。忙碌时阻止重复请求，不修改真实工具状态来伪装成功。主页的批量勾选、勾选数量和勾选操作隐藏，保留单个启停、全部启动／关闭和添加程序；已有选择数据与底层能力保留。

通用设置、各原生设置和外部程序编辑共用工作台遮罩窗口。支持淡入＋缩放、淡出＋收回、点击窗口外部／关闭按钮／Esc 关闭；内部点击不关闭，异步保存期间防误关，失败保留输入。窗口跟随工作台位置与尺寸，收起后恢复可用的原焦点。系统减少动画／高对比度时跳过位移、缩放。

beta.12 文件分类、推荐、用户覆盖及保存行为保留。后缀默认显示常用 18 项，可展开全部或直接分类／搜索；后缀与软件列表共用页面滚动，减少多层滚动条。程序输入和高级展开入口统一边角与线性图标。剪贴板默认关闭的连续复制选项、次数和保存仍有效；说明精简，完整规则可展开查看。beta.11 的微信／Edge 实际复制验证边界未改变。

工作台与设置采用已选的固定深色方向；原 A/B 及主题设置保留给文件快开的打开面板等辅助浮层，局部预览仍不会提前修改运行配置。

一轮独立视觉评审为 8/10。随后处理四项反馈：文件类型多层滚动、程序表单控件与留白、重复运行统计、设置冗余说明。WPF 的 100%／150%／200% 渲染和最小尺寸已检查，实际显示器 DPI 与高对比度桌面验收继续按原待办跟踪；没有把渲染图当作这些现场验收。

首次使用请先从托盘退出旧助手，再解压完整新目录运行 EousAssistant.exe；单实例保护会把第二次启动转交给现有进程。保留同目录全部依赖。原型 HTML 仍保留作为设计参考，运行程序已使用本版 UI。
