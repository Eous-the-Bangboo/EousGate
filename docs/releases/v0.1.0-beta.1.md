# EousGate v0.1.0-beta.1

EousGate 的第一个公开测试版。它是一个 Windows 11 本地工具：将一个或多个文件拖到主屏幕边缘，即可选择本机软件打开。

## 主要功能

- 支持主屏幕左侧、右侧和上侧接收条。
- 支持单文件、同类型多文件和混合类型多文件。
- 混合类型只显示能够处理全部文件的软件。
- 支持 Windows 桌面软件、打包应用和按扩展名配置的自定义应用。
- 支持浅色、深色、高对比度、面板外观和触发参数。
- 完全本地运行，不上传文件，不修改 Windows 默认文件关联。

## 下载与运行

1. 下载 `EousGate-v0.1.0-beta.1-win-x64.zip` 和 `.sha256` 文件。
2. 解压 ZIP 后运行 `EousGate.exe`。
3. 程序会驻留系统托盘；右键托盘图标可暂停、打开设置或退出。

## Beta 提示

- 支持环境为 Windows 11 x64 和主显示器。
- 当前不支持文件夹、多显示器边缘、自动启动和自动更新。
- 当前二进制未进行数字签名，首次运行可能出现 Microsoft Defender SmartScreen 提示。请只从本仓库 Release 下载并核对 SHA-256。
- Microsoft Photos 多文件激活、干净 Windows 11、DPI 和高对比度仍需要更多公开测试。

请通过 GitHub Issues 反馈问题，并避免提交私人文件名、完整路径或文件内容。
