# v0.2.0-beta.8 · 2026-10-17

- 开关确认状态改变时滑动并渐变，修复连续状态／能力通知在首帧前反复重置动画；保留处理中转圈、失败方向及系统减少动画设置。
- 修复普通权限助手直接启动要求管理员权限的 EXE 时返回 Windows 740：先正常启动，仅此错误交给 Windows Shell 授权；授权期间界面保持响应，取消授权／拒绝访问显示中文提示。启动参数和工作目录保持一致，启动后复核实际进程。
- 不自动提高助手权限，不更改系统兼容性设置，退出命令不自动授权；管理员程序停止可能需要自行操作。监控仍限当前用户及会话，换账号授权的程序不会作为当前用户程序管理。
