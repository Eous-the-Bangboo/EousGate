# v0.2.0-beta.15.3 · 2026-10-20

修复启动文件快开时显示“拒绝访问”的回归问题。

- beta.15.1新增的权限检测使用Query权限取得主令牌，再调用WindowsPrincipal.IsInRole；该方法内部复制令牌，缺少Duplicate权限时在查询阶段抛出SecurityException，模块尚未创建接收条就失败。
- 权限检测改为Query | Duplicate，仍只检查当前有效令牌，不请求UAC或改变程序权限。普通运行可继续启动文件快开；管理员运行仍显示拖放权限隔离及普通启动说明。
- 此前模拟提升状态的回归绕过了真实查询。本版默认权限回归先调用生产检测并与当前Windows令牌比对，再验证管理员提示与失败清理。

专项证据：`work/beta15-permission-baseline.log`准确复现SecurityException“拒绝访问”；`work/beta15-permission-fixed.log`确认真实查询成功。无其他原生模块互斥标记冲突时，使用隔离配置执行`--assistant-host-smoke`，两轮完整启动/停止、独立FileHop/WebHop停止、窗口清理和标记释放通过，见`work/beta15-permission-host.log`。该测试不操作用户软件或桌面输入，不代表完整资源管理器拖拽验收。

实现依据：[.NET WindowsPrincipal源码](https://github.com/dotnet/runtime/blob/main/src/libraries/System.Security.Principal.Windows/src/System/Security/Principal/WindowsPrincipal.cs)中的主令牌复制路径；修复前后均使用本机.NET 8运行时验证。

完整发布验证：SDK8.0.424，`publish.ps1`默认Release流程通过，79/79基础测试、真实权限查询、文件设置/剪贴板/窗口/助手/工作台/自定义程序/监控及专用进程回归全部通过，构建0警告0错误。日志：`work/beta15-permission-release.log`。
