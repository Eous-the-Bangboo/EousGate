# EousGate 入门说明

## EousGate 是什么？

EousGate 是一个放在电脑后台的小工具。你拖动一个或多个文件时，把它们靠近屏幕边缘，就会出现一个小面板。面板里会列出 Windows 认为可以打开全部文件的软件。

把文件继续拖到你想用的软件图标上，松开鼠标，文件就会用那个软件打开。

## 怎么使用？

1. 启动 EousGate。启动后它会出现在右下角的系统托盘里，不会一直挡在屏幕上。
2. 在资源管理器中选中一个或多个文件并按住鼠标左键拖动。
3. 把文件拖到主屏幕最左边，等待小面板出现。
4. 继续把文件拖到需要的软件图标上，然后松开鼠标。
5. 如果改变主意，按 `Esc`，或把文件拖回左边缘外面再松开。

## 面板里会显示什么？

EousGate 会使用 Windows 自己的“打开方式”信息，所以你看到的是电脑上已经安装、并且通常可以处理这些文件的软件。混合类型时只显示全部类型共同可用的软件。默认先显示 4 个，点击“更多”可以查看其他软件。

如果没有找到软件，面板会告诉你“未找到可打开的软件”，并提供打开 Windows 系统设置的入口。

## 出错时怎么办？

如果软件已经被删除、路径失效，或者 Windows 不允许启动它，EousGate 会显示原因，并让面板继续留在屏幕上。你可以换一个软件重试，或者取消这次拖拽。

## 第一版的限制

- 只保证一个屏幕，并且是主屏幕的左边。
- 不处理文件夹；文件和文件夹混合拖入时整批拒绝。
- 不会自动随 Windows 开机启动；需要使用时请手动运行。
- 不会联网，也不会上传文件名或文件内容。
- 首版优先支持 Windows 11，暂不承诺 Windows 10。

## 右下角托盘菜单

程序运行时，右键右下角的 EousGate 图标，可以暂停或恢复功能、打开设置、退出程序。暂停只影响新的拖拽，不会强行关闭已经打开的软件。
