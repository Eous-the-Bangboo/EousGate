# 开发日态记录

本目录记录项目每天实际发生的开发事项。日态由开发代理在每次任务开始、过程中和结束时维护，用于让下一次工作能从明确状态继续，而不是依赖聊天记录。

## 文件规则

- 每天使用一个 `YYYY-MM-DD.md` 文件，日期使用本地时区。
- 新的一天从 [`TEMPLATE.md`](TEMPLATE.md) 复制模板；历史日志不删除。
- 跨天未完成事项必须同时出现在当日日志和 [`TODO.md`](TODO.md) 中。
- `TODO.md` 使用 `TODO-*` 编号，状态只能是 `待办`、`进行中`、`已完成` 或 `阻塞`。
- 完成事项不得从 `TODO.md` 删除，只将状态更新为 `已完成`；详细验证历史继续保留在对应日态中。

## 更新时机

- 开始：写入目标、范围、当前阶段和预计验证方式。
- 过程中：补充完成项、风险、阻塞和新增待办。
- 结束：写入实际改动路径、验证命令及结果、未完成事项和下一步。

日态只记录事实和可验证结论，不粘贴完整日志、不记录文件内容，也不默认记录用户文件路径。
