# 开发日态补充：Windows 11 Mica

## 实际改动

- 新增 `Infrastructure/MicaWindowHelper.cs`，通过 DWM `DWMWA_SYSTEMBACKDROP_TYPE` 启用 Mica 材质。
- 设置中心和自定义应用编辑窗口保留动态主题底色并启用 Mica，避免完全透明客户端在部分 DWM 组合下渲染为黑色。
- 高对比度、非 Windows 环境或 DWM API 失败时保持现有主题回退，不阻塞窗口创建。
