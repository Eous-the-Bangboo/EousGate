# 开发日态补充：鼠标感知与多侧接收条

## 实际改动

- `UserSettings.EdgeBandPosition` 以兼容字符串保存 `Left`、`Right`、`Top` 的组合，旧配置 `Both` 映射为左右两侧，缺少字段时默认左右两侧。
- `App` 同时管理左、右、上三个 `EdgeDropWindow`，根据设置和暂停状态启用或隐藏对应接收条。
- `EdgeDropWindow` 按自身侧别定位，并在触发时采集鼠标屏幕坐标。
- `OverlayWindow` 接收鼠标锚点，按左右侧自动选择展开方向并限制在工作区边界内。
- 候选按钮保留并强化现有悬停、焦点和按下高亮状态。
- 接收条位置设置改为左侧、右侧、上侧三个复选框，支持任意组合；旧版 `Both` 值自动迁移为左侧+右侧。
- 右侧定位使用工作区右边界减去实际接收条厚度，上侧使用工作区宽度铺满并从鼠标下方展开弹窗。
