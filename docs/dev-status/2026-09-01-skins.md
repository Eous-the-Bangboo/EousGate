# 开发日态补充：三种皮肤材质修复

## 目标

- 修复 Acrylic 和 Clear 皮肤无法呈现真实材质的问题。
- 让设置中心、打开面板和自定义应用编辑窗口使用同一皮肤。

## 实际改动

- 修正 DWM 系统背景类型映射：Mica=`2`、Acrylic=`4`、Clear=`1`。
- DWM 设置成功后将 WPF 合成背景设为透明，避免客户端不透明表面遮住材质。
- 自定义应用编辑窗口接收当前 `SkinId`；主题刷新时一并更新该窗口。
- 新增 DWM 材质映射自动化测试。
- 设置中心暂时仅隐藏方案二/三；Acrylic/Clear 皮肤选项已恢复，供用户验证修复后的透明效果。
- 移除会导致无边框弹窗动画出现黑边的全局 WPF 透明合成设置，仅保留 DWM 材质类型映射。
- 打开面板不再启用 DWM backdrop；设置中心和自定义应用窗口继续使用 DWM，避免面板动画边界与系统材质合成冲突。
- 打开面板启用 WPF 分层透明窗口，移除无边框窗口动画期间暴露的黑色根背景。
